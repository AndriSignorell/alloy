# Graduate school admissions

Admissions decisions for 400 applicants to a graduate programme, used to
illustrate binary logistic regression.

## Usage

``` r
Admit
```

## Format

A data frame with 400 rows and 4 variables:

- admit:

  Binary outcome: 1 = admitted, 0 = not admitted.

- gre:

  GRE score.

- gpa:

  Grade point average.

- rank:

  Factor (1–4): prestige of undergraduate institution.
