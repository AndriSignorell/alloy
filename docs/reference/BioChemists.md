# Biochemists' publication counts

Publication counts for 915 biochemistry PhD students, used to illustrate
zero-inflated and count regression models. Originally from the pscl
package.

## Usage

``` r
BioChemists
```

## Format

A data frame with 915 rows and 6 variables:

- art:

  Number of articles published in the last three years of the PhD (count
  response).

- fem:

  Factor: gender (`"Men"`, `"Women"`).

- mar:

  Factor: marital status (`"Single"`, `"Married"`).

- kid5:

  Number of children under age 6.

- phd:

  Prestige of PhD programme.

- ment:

  Number of articles published by the mentor in the last three years.

## Source

Long, J. S. (1997). *Regression Models for Categorical and Limited
Dependent Variables*. Sage.
