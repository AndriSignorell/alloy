# Ordinal outcome: applying to graduate school

Survey data on 400 students' likelihood of applying to graduate school,
used to illustrate ordinal logistic regression.

## Usage

``` r
Ologit
```

## Format

A data frame with 400 rows and 3 variables:

- apply:

  Likelihood of applying to graduate school (ordered factor response: 0
  = "unlikely", 1 = "somewhat likely", 2 = "very likely").

- pared:

  Parental education indicator (1 = at least one parent has a graduate
  degree, 0 = otherwise).

- public:

  Type of undergraduate institution (1 = public school, 0 = private
  school).

- gpa:

  Student's cumulative undergraduate Grade Point Average (GPA).
