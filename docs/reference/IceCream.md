# Ice cream flavour preference

Preference data for 200 respondents choosing between three ice cream
flavours, used to illustrate multinomial logistic regression and machine
learning classifiers.

## Usage

``` r
IceCream
```

## Format

A data frame with 200 rows and 4 variables:

- id:

  Respondent identifier.

- ice_cream:

  Factor: preferred flavour (`"vanilla"` is reference, `"chocolate"`,
  `"strawberry"`).

- video:

  Hours of video watched per week.

- puzzle:

  Puzzle score.

- female:

  Binary: 1 = female, 0 = male.
